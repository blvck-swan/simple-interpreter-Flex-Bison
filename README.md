# simple-interpreter-Flex-Bison
A small interpreted language with Arabic/Darija‑inspired keywords, built usuing Flex (lexical analyzer) and Bison(parser generator), The language supports variables, arithmetic operations, conditionals, loops, input/output, and immediate execution, no separate compilation step.
How it works:  Lexer(projet.l):                                                                                                                                       -Converts source code into tokens(keywords, numbers, identifiers, operators).                                                                                         Parser(projet.y): -checks syntax against grammar rules.                                                                                                               -execute immediately when a complete command is recognized.                                                                                                           -Uses global variables (sum, sub, mul, divv) to accumulate results.                                                                                                   -Stores variables in an array.
